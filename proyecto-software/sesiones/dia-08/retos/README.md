## Nivel base - ¿Es plagio?

Para cada caso, di **sí o no**, y **por qué**:

1. Copias dos oraciones de un libro, entre comillas, con el autor y la página.
2. Lees un artículo, entiendes la idea, y la escribes con tus palabras sin mencionar el
   artículo.
3. Copias una tabla de una página web y le cambias los colores.
4. Le pides a una IA que te explique qué es una metodología ágil, lo entiendes, y escribes tu
   propio párrafo.
5. Le pides a una IA que redacte tu justificación y la pegas tal cual.

## Nivel extra - Detectar afirmaciones sin origen

Relee tu marco teórico y tu propuesta completos, buscando afirmaciones que **no sean tuyas y no
tengan origen**.

Ejemplos de lo que hay que encontrar:

> *"Los sistemas de gestión reducen los errores en un 40%."* ¿Según quién?
> *"El software a medida cuesta alrededor de USD 400."* ¿De dónde salió?
> *"Los negocios pequeños prefieren soluciones simples."* ¿Quién lo dice?

- [ ] Marca cada una
- [ ] Para cada una: consigue la fuente, o **reescríbela** para que sea una observación tuya
      con su origen

Y responde:

> ¿Cuántas encontraste? Si no encontraste ninguna, **búscalas otra vez**: casi siempre hay dos
> o tres.
