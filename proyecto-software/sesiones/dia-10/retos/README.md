# Retos del Día 10 - Historias de usuario

Día de parcial: retos cortos.

---

## Nivel base - Arreglar historias

Cada una tiene un problema. Di **cuál** y **reescríbela**:

1. "Como usuario quiero ingresar al sistema para poder ingresar al sistema."
2. "Como administrador quiero un botón de guardar."
3. "Como cliente quiero que el sistema use una base de datos MySQL para almacenar mis datos."
4. "Como propietaria quiero ver los pedidos para verlos."
5. "Como encargada quiero registrar pedidos, consultar el historial y generar reportes."

---

## Nivel medio - Tus historias

- [ ] **Tres a cinco**, no más
- [ ] Cada una con **rol específico** (no "usuario"), acción y **beneficio real**
- [ ] Cada una enlazada a los requerimientos del Día 9 que cubre
- [ ] **Tres o cuatro criterios** de aceptación por historia, en formato dado/cuando/entonces

Y la prueba del "para":

- [ ] Léele a un compañero **solo el «para»** de cada historia
- [ ] ¿Entiende **por qué** vale la pena construir eso?

---

## Nivel extra - Los casos que faltan

Para cada una de tus historias, agrega **al menos un criterio** de estos:

| Tipo | Pregunta |
|---|---|
| **vacío** | ¿qué pasa si no hay nada que mostrar? |
| **error** | ¿qué pasa si el usuario se equivoca? |
| **borde** | ¿qué pasa en el límite? (fecha de hoy, cantidad cero, texto muy largo) |

Y después, el mapa:

- [ ] Ordena tus historias por **flujo del usuario**, izquierda a derecha
- [ ] Marca la fila **MÍNIMO**: lo que ya resuelve tu problema del Día 2
- [ ] Compara la fila **DESPUÉS** con tus límites del Día 4: ¿coinciden?

Y responde:

> Si solo construyeras la fila MÍNIMO, ¿tu cliente tendría resuelto su problema?

Si la respuesta es no, tu fila mínimo está incompleta. Si es sí, ya sabes qué es lo primero que
tienes que terminar.
